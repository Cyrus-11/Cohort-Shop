# Tests

`npm test` runs the database suite against an isolated temporary PostgreSQL cluster. It checks RLS/ownership, database constraints, server pricing, checkout retries, concurrent cart writes, payment finalization, and email claim races. It does not call Supabase Auth, Paystack, or Mailgun.

`tests/app/webhook.test.mjs` calls the real webhook route handler (signatures, other event types, malformed payloads, unknown references, replays, provider outage, wrong amount). `tests/app/payments.test.mjs` runs the shared payment finalizer and webhook signature check against in-memory fakes (`tests/fakes/`) and a mocked Paystack `fetch`. It covers unfinished/failed payments, wrong amount, currency, reference and test/live domain, wrong owner, provider outage, concurrent and repeated confirmation, email rejection and timeout, and invalid signatures. The fakes mirror the SQL functions but do not replace the database suite. Automated tests must mock Paystack and Mailgun; they must never send real payments or emails.
